# 说明书解读法 —— 任意建库试剂盒的化学理解（写任何代码前必读）

> 定位：**通用转换器的入口层**。输入是一份你从未见过的手动建库说明书，
> 本层方法负责把它理解成结构化的"化学理解表"。化学细节全部来自说明书本身，
> 不依赖任何特定试剂盒的先验知识；理解表经用户确认后才进入台面设计与脚本生成。

## 〇、输入格式与阅读通道（双通道纪律 · 2026-09-04 定）

开读前先看格式，按通道分工读（说明书主流 docx，少数 PDF）：

| 通道 | 用法 | 负责 |
|---|---|---|
| **文本抽取** | docx → pandoc / python-docx（表格→Markdown 保真）；PDF 用内嵌文本层 | **一切数字**：体积、温度、时间、循环数——零转写误差 |
| **视觉读** | 转 PDF/图像后多模态逐页看 | **结构**：流程图、表格行列对齐、跨页表、双栏排版、脚注小字 |

**四条纪律：**

1. **数字以文本层为准**——多模态看数字可能看岔（µ/m、0/8），两者冲突时信文本层
2. **流程图必须视觉读**：docx 流程图是嵌入图片，文本抽取 100% 丢；
   凡有流程图 → 转 PDF 逐页看，分支/汇合点单独抄录（它们决定台面设计）
3. **加样表回读核对**：抽取完把加样表重新渲染出来与原文逐格对照一遍再进理解表
   ——数字抄错是 P0 级源头错误（一个体积错，装量/枪头/化学计量全错）
4. **版本对齐 + 小字扫描**：同一试剂盒常有多个日期版——开读前先问用户以哪版为准
   （或 diff 两版）；多档循环数/"×2 重复"/注意事项常藏在表格脚注，视觉读时专门扫

## 一、说明书的典型结构（按序通读，边读边抽）

建库试剂盒说明书（不论厂商）几乎都是这个骨架：

1. **试剂盒组分表**：试剂名 / 规格 / 数量 / 储存温度 —— 先全量抄录，这是试剂分类的输入
2. **流程图**：全局步骤骨架，标出分支（如样本分选）与汇合
3. **逐步操作**：每步一张加样表（试剂×体积×加入顺序）+ 操作说明（混匀/孵育/磁吸/离心）
4. **温控程序表**：温度×时间×循环数 —— 直接映射为 PCR XML（规则见 04）
5. **注意事项**：避光/冰上/轻柔混匀/勿涡旋/静置时间 —— 这些是参数约束的隐藏来源

**抽取纪律**：逐步操作里的每一步，必须落成一行五元组：
`[输入板/管] + [加入试剂及体积] + [操作类型] + [温控/等待] + [输出去向]`
落不成五元组的步骤 = 没读懂，回去重读，不要带着模糊进入下一步。

## 二、试剂分类：先认清每种试剂的角色

把组分表的每个试剂归入以下角色（名字认不出时，看它在流程中出现的位置反推）：

| 角色 | 识别线索 | 对自动化的约束 |
|---|---|---|
| **酶/酶混合液** | 反转录酶、二链酶、连接酶、聚合酶、UDG… | 冰上保存（温控位）；最后加入；轻柔混匀；**怕盐污染→分装板+新枪头**（见 05 模式2） |
| **结合类 buffer** | BB/bind buffer，出现在磁珠捕获/纯化加样步 | 高盐；用过的枪头盒不得续用于酶步骤 |
| **洗涤类** | WB/wash、80% 乙醇 | 磁架上操作不动板；乙醇现配/挥发→注意装液量与添加时机 |
| **洗脱类** | EB/TE/NF water | 低体积高精度（空气垫参数）；洗脱后产物去向=下一步输入 |
| **磁珠** | 磁珠/beads，常带比例（0.5×/0.8×/0.9×） | 比例决定片段选择方向（小比例去大片段留上清，大比例收片段弃上清）；用前必须重悬 |
| **接头/引物** | Adapter、primer、index | 微量、防交叉污染（一对一转板或预装）；可预装进反应板省转板步骤 |
| **底物/样本** | RNA/DNA 样本、dNTP | 样本永远不被枪头跨孔接触；样本板位置决定全流程布局 |
| **溶剂/其他** | 水、乙醇、片段化试剂 | 片段化试剂常需 85℃ 等高温处理（温控方法） |

**判断不出的试剂**：列入"存疑清单"问用户，禁止猜。

## 三、手工操作 → 自动化操作原语

手册动词与 960 操作原语的对照（逐句翻译手工步骤时用）：

| 手册说法 | 自动化原语 | 备注 |
|---|---|---|
| 加入 X μL 试剂 | aspirate + dispense | 体积直接取自加样表；多试剂注意手册的加入顺序 |
| 吸打混匀 / 轻柔混匀 | mix | 混匀体积≈孔内总体积的 50–80% |
| 涡旋振荡 | shake_on/shake_off（板兼容时） | 手册要求涡旋但板不能涡旋的，改 mix 并标注 |
| 短暂离心 | **无对应硬件 → 省略或贴壁慢打液替代** | 必须在自动化说明书里注明此差异 |
| 置于磁力架至澄清 | mvkit 到磁架位 + dely 静置 | 静置 120–300s；吸上清时 Z 高贴磁珠层 |
| X℃ 孵育 Y 分钟 | pcr_run_methods（XML 方法） | 温控表→XML 见 04 |
| 弃上清 | aspirate + empty 到废液位 | **废液路由**：先算总量再定废液板（见 05 三） |
| 80% 乙醇洗涤 | 磁架上不动板，加乙醇→静置→吸弃×2 | 经典模式，见 05 模式3 |
| 室温静置干燥 | dely | 别过度干燥（手册会给时间窗） |
| 转移上清/产物 | aspirate + dispense 到目标板 | 目标板可能就是下一步的反应板（单板化机会） |
| 分装到多管/多板 | 8 头逐列分装到分装板 | 防污染模式见 05 模式2 |

## 四、从理解到台面设计的推导问题清单

理解表完成后，回答以下问题，答案直接决定台面布局（硬件规则见 01）：

1. **板的数量与身份**：全程需要几块板？哪块是样本板、哪块可合并（单板化）？
2. **低温试剂**：哪些酶/试剂需全程低温 → 温控模块位（通常 6℃）
3. **酶步骤位置**：哪些步骤需要分装板+96 头转板防污染（所有"酶加到多样本板"的步骤）
4. **废液总量**：每个弃液步骤的体积×样本数 → 废液板容量核算（深孔板 1300μL/孔）
5. **长温育窗口**：哪个孵育最长（连接/PCR）→ 换台窗口与并行准备时机
6. **换台次数**：总耗材（枪头+板）能否一次摆下 → 最小化换台（见 01 板位总数）
7. **多档 PCR 循环数**：手册是否按投入量/样本类型等给出**多档推荐循环数**
   （如"≥100ng 用 12C，10–100ng 用 14C"）→ 全部抄进温控表，并在存疑清单里
   列为**必问项**：是否做成开机弹窗选择循环数的模块（实现见 04 §三）。
   **不要擅自定死某一档**——选不选该模块直接决定 XML 结构（方法簇 vs 单方法）
   与脚本交互（require2 弹窗），必须在理解表确认阶段问清

## 五、理解表输出格式（交付用户确认的中间表示）

生成任何代码前，先产出三张表给用户过目：

1. **试剂分类表**：试剂名 | 角色 | 储存条件 | 全流程总用量（含死体积预估）| 所属步骤
2. **操作序列表**：步骤号 | 操作原语 | 试剂/体积 | 温控 | 等待 | 输入板→输出板
3. **存疑与差异清单**：手册歧义点、手工操作无法直译处（如离心）、需要用户拍板的决策
   ——含**多档循环数是否做成弹窗选择模块**（见第四节问题 7）

**门禁**：用户确认理解表之前，不写脚本、不画台面。理解错了，后面全错。
