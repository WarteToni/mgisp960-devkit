# WD 版（WDesigner 图形界面）· 语法与工程模式

> 现状（2026-08-30 起）：.wfp 工程文件**可程序化生成**（格式已解析、实机验证，
> 见 `references/09`）——直接生成 .wfp 是首选路径。
> **参数设置指南**（台面表 + 逐步参数表 + 弹窗文本，用户照单在 WDesigner 里手设）
> 降级为兜底形态：用户没有可用模板 .wfp、或生成版反复报错时使用。
> 两种形态的参数都与 Python 直写版完全同源（同一套化学）。

## 交付物形态（给用户的 WD 设置指南包含）

1. **台面布置表**：24 板位 × 耗材型号 × 内容物 × 体积/孔（含开机台面 + 每次换台对照）
2. **流程步骤表**：每一步 = 操作类型（吸取/打液/混匀/搬板/磁吸/振荡/温控）+ 全参数
   （体积/速度/空气垫/Z高/延时/枪头盒与孔位）
3. **弹窗清单**：换台弹窗出现时机 + 取出/保留/放入三栏清单
4. **PCR 程序对照**：XML 方法名 ↔ WD 里 PCR 模块参数设置
5. **验证清单**：水跑重点项

## WD 语法速查（读/改用户导出的 WD 脚本时用）

WD 工程内嵌 Python（`.python/` 目录），特征：

| 特征 | WD 语法 | spredo（Python 直写） |
|---|---|---|
| API 前缀 | `a_pcr_run("X")` `a_aspirate({...})` 等 `a_` 前缀 | 无前缀 |
| 初始化 | `initialize()` | `init(spx96)` |
| 台面元组 | **9 字段**，首字段 `'POS1'` 全大写 | 7 字段，'Pos1' |
| 台面绑定 | 3 元组 / "temp" 二元列表 | 字符串式 pos_type_map |
| 弹窗 | `dialog(msg, None, None, "2:00:00")` 4 参（末参超时） | `dialog(msg)` 单参 |
| unload_tips | 带 `Tips` 键 | Well 形态 |
| report | 位置参数 | 关键字参数 |
| 功能标记 | Temp / Mag(DW) / HigherPosition 等 | Temp_Module / MagRack（仅 4 种合法） |

实例：V2.2 产线验证版导出的 .python/ 目录（WD 语法语料案例，路径见语料索引 S8；
液体参数现以 13/11 为准）

## WD 版 vs Python 直写版 · 选型建议

| 场景 | 推荐 |
|---|---|
| 现场有 WDesigner 且习惯图形化维护 | WD 版 |
| 要脱离图形界面直接改 .py / 快速迭代 / 弹窗交互（选循环数） | **Python 直写版**（一步法已验证：require2 弹窗、单换台、双语） |
| 两者参数 100% 同源 | 可同时交付（WD 供现场、直写版供迭代） |

**液体参数基准**：无论哪个版本，参数按三层体系取——`13` 模块规律 →
`11` 数据 → `05` 兜底（V2.2 清单只是已验证语料之一）。

## WD → Python（反向转换，功能 3 的返回方向）

两条路线，按优先级：

1. **WDesigner 原生导出（首选）**：在 GUI 里打开工程 → 导出，得到工程内嵌的
   `.python/` 目录（WD 语法：`a_` 前缀 / `initialize()` / 9 字段台面），
   再按 `references/02` §六的对照表逐条改成 spredo 直写语法（12 处惯犯见 08#5）。
   **WD 改参后必须重新导出**；只存 .wfp 不导出时，.wfp 是唯一权威源（踩坑 #14）。
2. **程序化解析**：按 `references/09` 的记录流格式解析 .wfp，取活动树 JSON，
   DFS 拍平后逐节点映射为 spredo 调用（对照表反向用；活动类型短名 ↔ API 名）。
   适合批量核对或无法打开 WDesigner 的场景。

**一致性核验**：活动树拍平顺序（GlobalSequence→Block/Parallel/Branches/Body
深度优先）与 py 执行顺序一致，可逐行对位做字段级 diff；配对算法用
"分段 + 单调指针 + 签名"，未配对项先核对是否为设计差异再下结论（08#14）。
