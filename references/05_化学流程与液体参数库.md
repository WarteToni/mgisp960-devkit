# 流程模式库与液体参数基准（化学无关）

> 定位：本文档是**化学无关**的模式库——具体试剂组分/体积/温控全部来自输入的手动
> 说明书，本库只提供"步骤→移液操作"的映射模式 + 参数取值基准。
> 适用于任意建库化学（RNA/DNA、捕获/打断/扩增文库）；新模式随新项目积累。
> 参数基准定位：本文是三层体系（13>11>05，见 INDEX）的**经验兜底层**；
> 数据查 11、模块规律查 13。V2.2 产线液体参数清单仅是语料案例之一
> （文件名与路径见语料索引 S7）。

## 一、流程模式库

### 1. 靶标捕获/富集——"结合-清洗-洗脱"骨架
oligo(dT) mRNA 捕获是其中一种；rRNA 去除、探针杂交捕获等按同一骨架映射。
**首例：oligo(dT) 磁珠捕获 mRNA（7 步模式）**
磁珠预处理（混匀后待用）→ poly(A) 结合（RNA+BB 上磁珠板，温育 oligodT_cap 80℃）
→ BB 清洗 → 80℃ 洗脱 → 再结合（提高纯度，二次捕获）→ Wash×2 → 终洗脱。
- 温育 = 板进 PCR 位跑 `oligodT_cap` 方法（80℃×120s→25℃×300s）
- 磁吸 = 板 mvkit 到磁架位 + `dely()` 静置，吸上清 `BottomOffsetOfZ` 贴磁珠层小心吸

### 2. 防污染分装板 + 96 头转板（通用核心模式，任何多样本加样都适用）
**问题**：8 头直接往含不同样本的反应板加液 → 枪头跨样本移动 → 交叉污染。
**解法**：8 头先把 Mix 分装到**空分装板**（枪头只碰试剂和空板）→ 96 头**一对一**
从分装板转进每孔样本（枪头不跨样本）。
- 分装板放功能位（磁架/振荡位只作放板用）是合法先例
- 转板枪头原则：含酶操作（连接酶怕盐污染）用**新盒**；捕获段用过的盒（BB 高盐）不续用

### 3. 磁珠法纯化（通用骨架）
加磁珠（0.5×/0.8×/0.9× 按化学）→ 混匀孵育 → 上磁架静置 → 吸上清（废液路由！）
→ 80% 乙醇漂洗×2（磁架上不动板）→ 干燥 → 水洗脱（可振荡辅助）→ 转移产物。

### 4. 双片段选择（左/右双轮）
第一轮磁珠（去大片段，回收上清）→ 第二轮磁珠（收目标片段，弃上清）→ 洗脱。

### 5. PCR 扩增 + 产物纯化
配体系（引物预装板+mix）→ 进 PCR 位跑所选循环方法 → 并行预分装纯化磁珠
→ PCR 产物过磁珠纯化 → 文库落收集板。

## 二、液体参数经验区间（兜底层；数据查 11、规律查 13）

| 场景 | 典型值 |
|---|---|
| 常规吸取速率 | AspirateRateOfP 20–100（黏稠试剂慢 10–20；水相 50–100） |
| 打液速率 | DispenseRateOfP 10–100（分层加样慢，废液快） |
| 空气垫 | PreAirVolume 4–15；PostAirVolume 0–5（高精度小体积才用 post） |
| Z 高 | 贴液面吸 0.3–0.5；排空=打完后液面−0.4（13 §七.4；无液面跟踪回落吹净 3–8）；混匀 loop 内 0.5–7 递变 |
| 混匀 | SubMixLoopCounts 10–20，MixLoopVolume 30–150（大体积大 loop） |
| 8 头逐列分装 | `BottomOffsetOfZ` 按液面下降递减（如 12.8-1*i），DelySeconds 0.5–2 |
| 磁吸静置 | dely 120–300（s） |
| 洗脱振荡 | shake_on(1200,1) + mix 组合 |

**原则：新项目不许自创参数——按三层顺序 13→11→本表取参；确需新值时标注"待水跑验证"。**

**Z 高与分档参数**：深孔板/PCR 板液面曲线 + 四场景分档参数速查已固化在
`references/11`（实测液面参数表）——
写液体参数时**先查 11**：吸液判"固定值 / 曲线跟踪"两种模式，打液按体积档取值；
11 未覆盖的项回落本表经验区间，标注"待水跑校准"。

## 三、废液路由核算

- 深孔板 1300μL/孔；路由规划后手工复核各板累计（板流模拟器的粗算会虚高，
  它把非废液转移也计入——以手工复核为准）
- 分流模式：一路进专用废液板（板位由台面设计定，参考案例用 POS23），另一路借纯化废板承接（省换废液板）

## 四、时间线优化

- 长温育（连接 15min / PCR）期间用 `parallel_block` 做磁珠预分装、试剂降温
- 人工换台卡在长温育窗口内（弹窗文案写明"15min 内处理"）
- 全程弹窗数尽量 ≤2（1 次换台 + 1 次结束）；弹窗 2h 超时会报错

## 五、并行纪律（硬件并发模型见 01；2026-08-31 实测+官方全量统计）

- **并行唯一合法形态（用户 2026-08-31 定）**：PCR/模块长等待期间，手臂去
  准备下一环节的试剂/MasterMix——即每个 Parallel = 1 模块分支 + 1 手臂预备
  分支（预备只碰试剂板/空分装板，不碰反应板）。任何其他并行（双臂、或与
  当前步骤主流程并发）一律禁止：官方 ScriptLib 58 处 parallel_block 0 处液体
  块，spredo 无锁，双臂并行=未定义行为。
- 96 头转板（加样到反应板）必须在对应反应 Wait 之后顺序执行。
- 审查法：对每个 Parallel 统计手臂分支数 >1 即违规；再对手册逐步核对
  "加液必须在某孵育之后"的顺序链。
