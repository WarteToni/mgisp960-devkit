# 自动化说明书生成法（HTML + A4 PDF · 通用去标签化）

> 风格参考（仅示例，每次都要问）：作者本地的一步法自动化说明书及其生成器
> （文件名与路径见语料索引 S7，本地快照）。
> 它只是版式/信息组织的参照，**不是默认母版**——每次生成前必须走下面的三问。

## 生成前三问（必问，不要猜）

1. **项目名**：反问用户确定——说明书标题、脚本文件名、交付包名都以它为准。
   不得自拟带公司/品牌字样的名字；用户反问"名字怎么定"时，给 2-3 个命名建议供选。
2. **设计文稿**：问"是否需要特殊的设计文稿参考？"
   - **有** → 用户提供设计稿 → 接入设计规范排版：
     OpenDesign Cloud（open-design MCP：`get_artifact` / `get_design_context`）
     或 Figma MCP（`get_design_context` / `get_screenshot`）取色板、字体、版式，
     按设计稿生成说明书样式
   - **没有** → 生成常规普通版式：中性简洁、**无任何 logo、无品牌色**
3. **母版选择**：问是否用一份已验证的同类说明书作母版（走方法 A 克隆+定点替换），
   还是按 12 节标准结构从零生成（方法 B；范例排成 16 页）。**旧母版只是风格参考，每次都要问。**

## 方法 A：克隆 + 定点替换（有母版时，不要从零排版）

1. 母版 = 用户确认过的已验证同类说明书 HTML
2. 生成器 = Python 脚本：读母版 → 按替换表定点替换（约 40 处）→ 写新 HTML
   （模板见 `scripts/生成自动化说明书_模板.py`）
3. **替换表三原则**：
   - **前缀独立条目**：被其他替换改写过的文本，用唯一前缀定位（替换顺序敏感，
     长句先被部分改写会导致后续完整句失配）
   - **计数断言**：每处替换后 assert 新标识出现次数 == 预期（防漏替换）
   - **旧标识清零断言**：结尾 assert 旧版本号/旧脚本名/旧 URL 出现 0 次（防残留）
4. 图片：base64 内嵌 HTML（单文件自包含，但体积大）；**母版里带 logo 的图必须
   删除或换成中性占位图**（内嵌图无法文本检索，需人工逐张核对封面/页眉/页脚）
5. PDF：headless Chrome 转换（16 页、插图完整、页眉页脚关）：
```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="说明书-A4.pdf" "file://$(pwd)/说明书.html"
```

## 方法 B：12 节标准结构从零生成（无母版时；范例排 16 页）

按下面的 12 节结构逐节组织内容，版式用普通中性样式（干净排版、无 logo）。
内容来源 = 化学理解表 + 脚本台账 + 台面设计，逐页与脚本核对（见"内容一致性纪律"）。

## 去标签化红线（交付前强制）

- 封面、页眉页脚、正文、图片**不得出现任何公司名、品牌、logo**——
  这是通用化 skill，任何人使用都应得到中性产物
- 生成器里定义**品牌词清单**（旧厂商名、品牌关键词、旧项目公司字样），
  生成后逐词 assert 出现次数 == 0（模板已内置该断言骨架）
- 产品名用试剂盒名本身或用户指定名称；"XX 公司出品/技术支持"类字样一律不写
- 交付前把"品牌词清零"列入验证清单，与四层自检同级

## 12 节标准结构（通用自动化说明书式样；范例排成 16 页）

1. 封面（试剂盒/项目名 + 流程副标题 + 版本）
2. 产品内容 / 规格型号
3. 存储与运输
4. 自备耗材清单（吸头/板 + 数量表）
5. 样本要求与制备
6. **台面布置**（24 板位表：耗材类型 + 内容 + 体积/孔）★核心页
7. **操作流程**（软件启动步骤：导入脚本/XML → 选参数 → 运行）★核心页
8. **换台提示**（对照表：取出/保留/放入 三栏）★核心页
9. 实验原理与流程概览
10. 质控与定量
11. 常见问题
12. 注意事项（弹窗及时处理、废液容量、水跑验证项）

## 内容一致性纪律（与脚本核对）

- 台面表、换台三栏清单、耗材数 = 从脚本的 `first_feature`/`SWAP1_POS`/弹窗文本**逐项核对**
- 弹窗文本与说明书换台清单必须互相印证（历史教训：弹窗写"取出8盒"而逻辑是
  Pos5 保留——说明书对、弹窗错，实机会出事故；模拟不校验枪头盒存在性）
- 温控程序表与 XML 方法参数逐项核对（min↔s 换算）
- 页面溢出检测：生成后检查每页内容高度 ≤ 版心（表格大页易溢出，
  压缩手段：合并耗材行、精简 note、删保留行并入 note）
- 说明书里的脚本文件名、拷贝路径必须与交付包实际结构一致（更名后重新生成）

## 配套现场文档

另出一份《单步运行说明》（Markdown）：摆台面 → 启动选参数 → 各阶段自动内容 →
换台人工操作 → 收样清台。比说明书更口语化，给水跑/操作员对照用。同样遵守去标签化。

官方交付三件套还含 **Check point 文档**（见 SKILL.md 交付包结构）：可从验证清单/
水跑重点项导出——检查点 × 预期现象 × 不达标处置，同样去标签化。
