## 第 1 层：语法编译

```bash
python3 -m py_compile 脚本.py
```
双语版加做 **AST 等价**（字符串置空后语法树一致 → 证明英文版零逻辑改动）：
```python
import ast
def skeleton(p):
    t = ast.parse(open(p).read())
    for n in ast.walk(t):
        if isinstance(n, ast.Constant) and isinstance(n.value, str): n.value = ''
    return ast.dump(t)
assert skeleton('zh-cn.py') == skeleton('en-us.py')
```

## 第 2 层：板流与容量模拟（自检_全面_模板 自动化）

逐行解析脚本，维护虚拟台面状态：
- 每次 `mvkit(A,B)`：A 必须有板、B 必须空（对应软件 loose_check）

- `load_tips`/`unload_tips` 记账：枪头盒消耗、POS5 八头盒用列数 ≤12、

该工具还附带：换台弹窗三栏与换台后台面逐项互证（踩坑 #6）、

## 第 3 层：参数合法性核对（经验基准，不做基线 diff）

本 skill 按经验知识**生成**程序，不照抄基线做 diff。参数逐个对照经验基准：
- Z/速率/气垫/延时 → `references/11` 分档速查 + 液面曲线推导
- 模块级配法（结合/去废液/乙醇洗/洗脱回收/分装/混匀）→ `references/13`
- 自动项：自检工具的 J/K 检查（枪头量程、排液 ≤ 吸液、公式 Z 提示复核；
  负 Z 官方允许不报错）
- 无出处的参数不许自创，标注"待水跑校准"（05 原则）

## 第 4 层：软件模拟（用户在控制软件执行）

- 用户把脚本拷到 `C:\MGISP-960\Engineer\ScriptLib\{项目}\zh-cn\`，模拟启动
- **报错取证要 Script.log**（导出日志 zip），不要弹窗截图——截图会丢帧、
  行号含软件 wrapper 偏移（本平台实测 ≈139 行：`脚本行号 = 日志行号 − 139`）
- 弹窗及时点继续（2h 超时报 `SystemError: Operation over 02:00:00`，非 bug）
- 模拟通过 ≠ 实机安全：模拟不校验枪头盒物理存在性、不校验功能位放板物理兼容
