## 二、分档参数速查（源自同一工作簿「100&960」表）

体积档：`2-10 / 10-50 / 50-100 / 100-150 / >150 μL`；液体类型两分：
**普通试剂（ER/PCR 体系）** vs **黏稠试剂（连接类）**。四场景：反应体系配制 /
混合液分装 / DNA 样本 / 磁珠分装。

### Z 相关速查（核心）

| 场景 | 操作 | Z（mm，按体积档） | 权衡备注 |
|---|---|---|---|
| 体系配制 | aspirate | 0.3（全档） | |
| 体系配制 | empty | 1 / 1 / 2 / 2 | 低→气泡；高→排液不完全 |

### 气垫/速率/延时速查（要点）

- **PreAirVolume**：普通 5-10；黏稠 5-15（体积越大越大）；mix 场景同量级
- **PostAirVolume**：常规 2（DNA 样本 0）
- **AspirateRateOfP**：普通 10→50 随体积升；黏稠 10-20；磁珠 20-50
- **DelySeconds**：普通 0.5-1；黏稠 1-5（大体积取大值）
- **MixLoopVolume = 0.8×孔内总体积**；**DispenseVolumeAfterSubmixLoop 与
  PreAirVolume 一致**；SecondRouteRate = 38
- **磁珠预混匀特例**：MixLoopAspirate/DispenseRate **200-250**（重悬需要高速）、
  SubMixLoopCounts 15-25、SubMixLoopCompletedDely 5s——磁珠重悬充分性直接影响
  片段选择与回收率，不许降档

## 三、Z 推导规则

> **液面先行（用户 2026-09-06 定，本节总纲）**：动态液面不是逐个活动"就步"推导，
> 而是**写参数之前先跑全流程账本**（`scripts/账本_全流程液量模拟_模板.py`，
> 方法论 13 §十；SKILL.md 流水线 S3），每个 Z/公式/排空液面锚/混匀双约束
> **从账本液面导出**；本节的推导法用于设计公式形状与校验，不替代账本。

### 模式选择（先判断再推导）

| 液面状态 | 模式 |
|---|---|
| 液面高且基本不降（单点取液、消耗占比小） | **固定值**：直接取第二节场景表（aspirate 0.3-0.5） |
| 液面随流程显著下降（8 头逐列分装、跨程板多次取液） | **曲线跟踪**：按液面曲线逐次推导（下） |
| 吸上清贴磁珠层 | 磁吸场景，见 05 模式 3，不在本文范围 |

### 曲线跟踪推导（吸液）
1. **消耗台账**：按流程对每孔的消耗顺序算"第 i 次吸取前液面高 h(i)"
   （8 头逐列=同列顺序消耗；96 头=一次消耗；循环变量按最大次数取上限）
2. **枪头位置**：首个 `Z = h(1) − 0.5~1mm`（入液面之下）；之后随液面递减，
   写成循环公式（如 `h0 − k*i`），k 由曲线斜率×每列消耗量推出，注释写明出处
3. **下限保护**：负 Z **官方允许、无限制**（课程 6；本工具包历史禁令 2026-09-02
   解除，见 13 铁律 2）。推荐默认极低正 Z（0.1–0.3）+ 降速（5–10）——免标定最稳；
   负 Z 刮底须水跑标定；逼近死体积提前换板/换孔，不硬吸
4. **保守化**：液面估计宁低勿高（挂壁/挥发/读数误差）；乙醇板等挥发场景余量加大

### 打液（dispense/empty）
- **排空（empty）首选液面锚**（13 §七.4 双档制）：有液面跟踪时 **Z = 打完后
  液面 − 0.4mm**（带宽 −0.25~−1.0，气泡冒出即破、残液零挂壁）；无液面跟踪时
  回落第二节场景表体积档 Z——"低→气泡、高→排液不完全"是厂商标定权衡
- **液面上方加样**（防飞溅场景）：Z = 当前孔液面高（查曲线）+ 0.5~2mm
- **液面下加样**（手册要求时）：液面之下，配新枪头防沾液交叉
- **黏稠/起泡试剂**：贴壁慢打（孔壁上部 + 低 DispenseRateOfP）

### 混匀（mix）
- 底部 Z 与 InLoop/AfterLoop 递变范围取第二节场景表；再用液面曲线校验
  loop 全程在液面之下、不触底、总体积 50-80% 时不溢出
- **双约束判定式（用户 2026-09-06 指令，硬规则，按孔内最小可能体积核算）**：
  ① 抽走不露出：`mZi ≤ level(最小体积 − MixLoopVolume) − 0.5`
  （例：孔内可能刚好 50µL、mix 40µL → 抽后 10µL 液面 2.0mm → mZi ≤ 1.5）
  ② 收尾液下排完：`mZa ≤ level(最小体积全容量) − 0.3`
  （收尾打回时孔已回满，枪头必须在全容量液面之下把液体排完，不是"液面之上防溅"）
  ③ 体积上限：`MixLoopVolume ≤ 0.8 × 最小体积`（末轮井内变少时尤其要复核）

## 四、与实验流程的结合（思考维度）

1. **消耗顺序建模**：分装板每列被 8 头顺序吸→液面逐列下降；反应板被 96 头
   一次转→单点液面；先画"每孔消耗台账"再定固定值还是曲线跟踪
2. **跨程板分段规划**：一块板供多阶段（如水板跨程）→ 按阶段划分装液量，
   Z 序列全程累计计算，防止后段吸空
3. **挥发与挂壁**：乙醇板、长程敞口板液面随时间下降 → 安全余量加大
4. **输出物**：每板位一张"吸液 Z 序列表"——进代码注释（推导依据）+
   进验证清单（07 水跑重点项 #5：液位追踪是否跟得上实际液面）

## 五、写脚本时的应用清单

1. 写液体段前，把每个板位的耗材对号 → 查第一节曲线 + 第二节场景表
2. 吸液先判模式（固定值 / 曲线跟踪）；跟踪模式的循环公式注释推导依据
3. 打液 Z 按场景表体积档取值；特殊加样方式（液面下/贴壁）注释标明依据
4. 混匀参数按场景表 + 液面校验
5. 曲线/表格未覆盖的耗材或场景回落 05 基准，注释标"待水跑校准"
6. 水跑实测与推算不符 → 回填第一节曲线 + 更新脚本，形成闭环
7. **工作流 C（审查）**：本文是 10 的 **G 维定量基准**——残留折算、回收最大化、
   速率匹配全部用本文曲线与分档表核算
8. **模块级配法**（结合/去废液/乙醇洗/洗脱回收/分装/混匀各模块的完整参数约定）
   见 `references/13`——本文提供数据，13 提供化学模块层面的组合规律
