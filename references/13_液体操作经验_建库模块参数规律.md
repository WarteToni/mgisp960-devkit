# 液体操作经验 · 建库模块参数规律

> 定位：模块级经验规律——11 管"曲线/分档数据"，本文管"建库化学模块该怎么配"。
> 来源：外部官方脚本 ×2、DNA DOP/酶切建库实机验证版 ×2、V2.3 产线版、一步法，
> 通读建库逻辑后交叉验证（2026-09-01），**规律已经用户确认**；
> 2026-09-02 用 MGI 官方培训课件（课程 6/7/8）交叉印证并增补（装量/分装/样本数规则）。
> 用途：写脚本（工作流 A）按模块查表取参；审查（工作流 C 的 G 维）按本文判定。

## 铁律（用户确认的边界）

1. **回收吸取量 = 洗脱体积 − 2~3μL 安全余量（防吸磁珠），不许吸满**。
   官方背书：课程 8 示例"洗脱 21μL 取 19 / 32μL 取 30" = −2μL。
2. **负 Z 官方允许**（课程 6 明示：BottomOffsetOfZ"高度可以设置为负数，没有限制"）。
   本工具包历史上"禁止负 Z"的约定**已于 2026-09-02 经用户解除**；推荐默认仍是
   **极低正 Z（0.1–0.3）+ 降速（5–10）**——免标定、最稳；用负 Z 刮底则需水跑
   标定（防撞底/刮珠）。
3. **post-air 以 `references/11` §二分档表为准**：普通试剂 2、DNA 样本 0、
   乙醇去除 2；不引入脚本语料里的个例习惯。
   官方出处（课程 6）：PostAirVolume 目的 = 防止表面张力小的液体（如乙醇）漏液。
4. **Z=0 是磁吸位特权，不是通例**（用户 2026-09-06 划界）：磁吸后磁珠贴侧壁，
   底部中央为无珠区——去上清/吸乙醇/收产物用 Z=0 吸得最净且不吸珠（§一）。
   **试剂源吸取禁止盲目 Z=0**：源井液面高（深孔板装到 20mm+），贴底吸有三重
   风险（吸入底部沉聚组分致酶/盐不均、枪头口贴死孔底吸液不稳、长液柱静压），
   一律按 11 曲线取液面下正常没入深度。

## 一、磁珠法纯化骨架：逐模块参数约定

骨架：结合 → 磁吸 → 去废液 → 乙醇洗×2 → 晾干 → 洗脱 → 磁吸 → 回收。
试剂角色：乙醇=洗盐洗酶+脱水（挥发快、残留抑制下游酶，必须吸净）；
NF-water/TE=低离子洗脱；磁吸后磁珠贴**侧壁**，底部中央可贴近吸。

| 模块 | Z | 速率 | 气垫/等待 | 要点 |
|---|---|---|---|---|
| **结合**（样本→磁珠板） | 吸样本 0.1–0.5；打进磁珠板 2–4 | 吸 10–20，打 20–40 | mix 25 loops；**结合静置 240–300s，含连接酶的黏稠体系 ≥300s** | 打液在磁珠液面上方，别冲散珠层 |
| **去废液** | **0.1–0.5（极低正 Z）** | **10–30（慢，防带珠）** | pre 5–10 | 体积大/要吸净→**分段吸**（100@Z0.5 + 90@Z0.3，Z 递降）；排废液 Z 用**上升公式**（2+3*x / 10+x / 17+2*x）+ TipTouch 蹭壁（Height 15–22、OffsetX 2.5–3） |
| **乙醇洗 ×2** | 吸乙醇按乙醇板液面跟踪（如 16.5−2*x）；打在珠层上方 Z=4–5；去乙醇 0.1–0.3 | 吸乙醇 **100（最快）**；打 20–30；去乙醇 30–50 | pre 5 **post 2**（官方用途：防乙醇漏液）；接触 30–150s | 打乙醇别冲珠层；**必须悬空**；**165µL 量程红线化解（吸+前吸+后吸 ≤165）**：悬空打乙醇按"吸 152+57（前吸 10/5、后吸 2）→ 每轮交付 209"配对去乙醇"吸 155+55（前吸 10/5）=210"，收支平衡且全程在带滤芯保证量程内；配对一方总量超 165 时同步调整另一方，勿只改一半（枪头口悬于液面上方不没入——防交叉，也是打乙醇枪头可全程复用的前提，12 §二，用户 2026-09-09 确认）+ **靠壁排净**（残液顺壁流尽，§七.4c）；两轮可**补偿吸**一次 10–15μL 低 Z 慢速吸残留乙醇（"酒精吸干净"的显式动作） |
| **晾干** | — | — | 120–180s | 乙醇挥发窗口，别过度干燥 |
| **洗脱** | 吸水 0.5–1；打珠板 1–3 | 吸 20–50，打 10–30 | 振荡 1200rpm×2 段（中间停顿）或 mix 15 loops；**静置 60–120s**；磁吸 100–120s | 洗脱体积刻意小（终产物 22–30μL=浓缩；下游要转大量上清才用大体积如 104μL） |
| **产物回收** | **0.1–0.3** | **5–10（最慢）+ dely 1–2s** | pre 5 | 吸取量=洗脱体积−2~3μL；打入收集板低速（10–30）防飞溅；可选**同枪头连吸**下游 mix（23+25μL），珍贵产物零残留转移+省枪头 |；补偿吸量 > 孔内残液时属设计性过抽（吸残液膜），账本口径单独豁免或减量至 ≤残液 |

## 二、试剂分装（酶/Mix 八头逐列）

| 项 | 约定 | 原因 |
|---|---|---|
| 吸液 Z | **液面跟踪公式**（按 11 曲线推导，如 `4.3−4*x`、`12.8−1*i`） | 同一孔被逐列取用，液面持续下降 |
| **回打平衡** | 吸完先打回 2~5μL 到源孔（rate 2–5），再逐列分装 | 排枪头口气泡、平衡体积，保证每列体积准确——每个 mix 分装都应有这一下 |
| 分装速率 | ≥25μL → 10–20；**≤10μL（接头/引物）→ 2–5** | 微量防滴挂 |
| 黏稠试剂（连接类） | 吸 10–20，dely 加到 2–10；pre-air 15–20 | 挂壁、吸不足风险 |
| 收尾 | empty 余液 + TipTouch | 防滴落 |
| **分装源井 Z** | bulk 井逐列消耗后液面**加速下降**，线性公式会吸空 → 改用**每列 Z 表**（元组索引 `ZS[x % n]`），数值由账本实测液面导出（吸前液面−2mm，下限 0.3） | 一次性修正线性公式的标准动作（2026-09） |

## 三、混匀约定

- **磁珠预混匀**：180–250 高速、15–25 loops、dely 5——重悬充分性直接决定
  回收率，**不许降档**（11 §二同此规则）
- 反应体系混匀：80–180 按黏度、20–25 loops；mixvol = 孔内总体积 50–80%；
  inZ/afterZ 按液面定（11）
- 小体积体系（<30μL）：mixvol 13–20、inZ 2–3、15–20 loops
- **混匀双约束（用户 2026-09-06 硬规则，按孔内最小可能体积算）**：
  ① mZi ≤ level(最小体积−mixvol)−0.5（抽走后枪头不露出）；
  ② mZa ≤ level(最小体积)−0.3（收尾在全容量液面之下排完，非"液面之上防溅"）。
  审查发现工厂原值多处恰贴液面或抽完露出（如结合混匀 mZi=4 而抽后液面仅 1.55）——必查

## 四、与语料的历史差异（留档，不跟）

- **负 Z 刮底**（−0.2~−0.7）：负 Z 官方允许、限制已解除（2026-09-02），
  可按需采用（须水跑标定）；极低正 Z + 降速为免标定替代方案，两种并存
- 分段吸（去废液两段、Z 递降）：**保留**，这是"多来几次"的正解之一
- 同枪头连吸产物+mix：保留（场景合适时用：产物珍贵+下游立即混匀）

## 五、审查要点（供工作流 C / G 维对照）

| 发现 | 定性 |
|---|---|
| 回收/去废液速率 >30 或 Z 未压低 | P2（带珠风险），建议降到 5–20 |
| 回收吸取量 ≥ 洗脱体积（无安全余量） | **P1**（吸磁珠风险） |
| 负 Z（官方允许，无限制） | 本身不算违规；磁珠位给 P3 建议：确认已降速或经水跑标定 |
| 排废液 Z 固定不上升 | P2（液面升高后枪头插液/滴落），改上升公式 |
| 黏稠体系结合静置 <300s | P3 建议 |
| 分装无回打平衡 | P3 建议 |
| 乙醇洗后无补偿吸、且下游对乙醇敏感 | P3 建议 |
| 打乙醇未悬空（枪头没入液面）/ 打去共用枪头 | P2（交叉风险：打失复用资格、去侧污染打液侧；12 §二） |

## 六、试剂装量与分装准备（官方课程 8 · 说明书"试剂装量表"的规则）

| 项 | 官方规则 | 说明 |
|---|---|---|
| mix 配制倍数 | 按 1X 用量配 **13X–14X**（体积小/黏稠取更大系数） | 保证分装 12 次充足；实例 ERAT 14X / Ligation 13.5X / PCR 13X |
| Enzyme 装量 | **装量 = 使用量** | Buffer 会转入 Enzyme 中混匀后分装，故不额外多配 |
| Buffer 装量 | **装量 = 使用量 + 10–30μL** | 补偿转入 Enzyme 时的转移/挂壁损失 |
| 最终装量 | 通过测试（水跑）确定 | 表中数值为起点，实测定稿 |
| 分装布局 | Buffer/Enzyme 分装到深孔板**某一列**备用；乙醇、TE 各自**整板 96 孔** | 与 12 的防污染分装模式同源 |
| 混匀分装方式 | 8 头扎 1 列吸头，把 Buffer 加入 Enzyme 列混匀，混匀后把 Mix **分配 12 次**至 96 孔板 | 即"同枪头混匀+逐列分装"模式的官方出处 |
| 样本数 | **12–96，且为 12 的倍数** | 不满 96 时试剂列与样本位置对应（24 样本=试剂列 1-2、样本行 A-B） |


## 七、气垫计量铁律（2026-09-03 实证：V2.7 全量审计 + 官方 test.redo.py）

枪头内从口向内：**后吸空气 → 液柱 → 前吸空气**；打液从口排出（后吸先出）。
底层为**位移型**（官方 test.redo.py 存在 vol_compensate() 手动补偿函数即证）：

1. **前吸 + 部分打：计量正确**——前吸在顶部不参与，dispense 写原目标体积 ✓
2. **后吸 + 部分打：亏体积**——后吸空气先排出占用活塞位移，实际液体少打
   PostAir 体积；要么 DispenseVolume 写"目标+PostAir"，要么改用排空收尾。
   **原厂全部语料 0 处此组合（刻意避开）——设计时同样避开**
3. **后吸 + 排空：正确且推荐**——排空时后吸空气最后排出，把残液顶净
4. 排空 Z 手法（2026-09-06 终版·双档制，锚点=液面优先）：
   - **有液面跟踪**（11 §一实测表 + §十账本）：**排空 Z = 打完后液面 − 0.4mm**
     （可接受带宽 −0.25~−1.0mm）。机制：前吸空气只没入 0.4mm，冒出即破——
     气泡行程最短不飞溅；残液零挂壁直接并入目标液体，§八净积累口径严格成立。
     黏稠/易起泡体系优势更大。多轮打液（同枪头逐列）每轮贴各自打完后的液面取低档
   - **无液面跟踪**（新项目早期/无实测表）：回落原厂相对手法——低位打主体 →
     排空抬高 1~2mm 贴壁慢吹（防飞溅；2026-09-03 语料总结，历史留档）。
     局限：液面未知只能以主体 Z 为相对锚，效果常落在液面之上，残液挂壁损 0.5~2µL
   - 废液排空：贴累计液面（本就以液面为锚）
   - 枪头复用视角：主体打液在低位已浸没枪头口，排空 ±0.4mm 不改变外壁湿润
     程度——复用资格由"枪头接触过什么液体"决定（12），与排空位置无关
4b. **"试吸 2µL@Z20+排空" = 戳封膜孔**（用户确认 2026-09-03）：试剂板封膜时
    用枪头在孔口高位（Z≈20）假吸捅膜开孔，不吸入液体——核算装量/井内余量时
    **不计入**（曾误当回打平衡多算 2µL）
4c. **悬空打液（乙醇）排空 = 液面上方靠壁**（用户 2026-09-09 确认原则）：
    打乙醇必须悬空（枪头口不没入液面——复用资格前提，12 §二），本条 §4 的
    −0.4mm 液面锚（需浸没）不适用；改靠壁收尾让残液顺壁流尽，打得尽可能干净。
    **靠壁 = TipTouch 参数组**（用户 2026-09-09 确认）：OffsetX 一般 **2mm 左右**
    贴孔壁内缘，Height 按需调（悬空场景 = 液面上方蹭壁）；WD 导出语料实例
    Height 15–22 / OffsetX 2.5–3（§一排废液行）。残留待查：spredo 纯直写环境
    TipTouch 键是否被读取（02 §三，查源码存档可自答）
5. 8 头分装（POS5 用完丢 POS24）应带"排空回源井"收尾——带液丢枪头会滴液
   （原厂 4 处分装仅 1 处做了收尾，属遗留缺陷）

## 八、整板净积累原则（用户 2026-09-03 纠偏，最高优先级审查逻辑）

**不要单看某一次枪头操作，要看多次操作后目标孔的净积累量。**
"部分打 V + 排空（同孔）" = 实际交付 = 吸入总量（排空把余量全部回收进目标孔）：
- 磁珠"吸50→打48+排空"：目标孔实收 **50**（非 48）——标注/核算/审查一律按 50
- 台面装量注释、说明书装载表、反应体积核算都必须按净积累口径
- 审查时逐孔建"净积累台账"：Σ(打入) − Σ(吸走) = 孔内实有量
- 例外确认：排空目标≠部分打目标（如分装收尾排空回源井）时，目标孔只计部分打量

## 九、吸液洁净度分级（C1–C4 判断法 · 2026-09-04 建框架）

> 不是所有"吸"都要求同样干净。写脚本（工作流 A）先给每一步定级、再按级取参；
> 审查（工作流 C 的 G 维）反过来：拿每一步参数反推它隐含的洁净度等级，
> **级与参不匹配就是问题**。

**定级三问**（对每一吸依次问，答案决定等级）：

1. 吸走的东西是什么角色？——杂质 / 产物 / 过量试剂
2. 留下（或残留）的东西会不会伤害下游？——乙醇/盐/酶残留抑制反应、磁珠 carryover
3. 体积误差会不会改变化学结果？——分选 cutoff、化学计量比

| 级 | 典型场景 | "干净"的定义 | 参数签名（数值以本文已验证行为准） |
|---|---|---|---|
| **C1 清除型** | 去废液、终洗去上清、乙醇去除、分选磁珠后的上清 | **吸得越净越好**；上限同样是不许吸珠 | 极低 Z + 慢速 + 分段吸 Z 递降、乙醇后补偿吸 10–15μL（§一去废液/乙醇洗行） |
| **C2 回收型** | 洗脱后产物回收 | 方向反转：**宁少勿带珠**——少吸是可控的量化损失，吸珠是下游污染 | 最慢 5–10 + dely 1–2s、Z 0.1–0.3、吸取量=洗脱体积−2~3μL（铁律 1） |
| **C3 精确型** | 分选/片段筛选：每步吸入体积就是 size 边界 | **体积准确就是干净**——多吸少吸都直接改文库大小分布 | 中速、液面跟踪、回打平衡（§二）；禁用多吸/补偿类手法；本库暂无分选参数行，随项目积累 |
| **C4 宽容型** | 加试剂、分装源吸取、混匀、戳膜假吸 | 干净度无关——试剂过量，每孔交付量由打液体积决定（§八净积累口径） | 常规档（11 分档）；只防吸空与气泡（回打平衡） |

**三条推论：**

- **同一步骤内部也有分级**：去废液前段珠吸得牢、体积大可快吸；末段贴近珠面必须慢——
  §一"分段吸 Z 递降"正是此原理；C1 的"吸净"永远以不触珠为上限
- **C1 与 C2 冲突时 C2 优先**：宁可留 2–3μL 残液（下一轮 wash 稀释）也不吸珠——
  铁律 1 的安全余量就是这个取舍的数值化
- **C4 容忍"不干净"≠容忍"错"**：吸空、气泡、带错液体在 C4 同样禁止，只是对"残留多少"无要求

## 十、全流程液量账本（模拟器方法论 · 2026-09-06 V2.9 实战固化）

§八净积累原则的机械化实现：模拟 wfp/spredo 活动树执行，逐孔累计体积+液体
身份，输出每个液体操作时刻的液面。工具：`scripts/账本_全流程液量模拟_模板.py`
（CONFIG 装载定义 + 通用引擎，**只读不写** wfp）。

**通用设计（换项目不变）**：
- 液面一律实测表插值现算（11 §一硬规则），账本只记 µL
- **液体身份随板移动**：每井维护 tags，MvKit 搬板身份跟走，注入按有序去重
  合并（mtag）——回答"这孔里现在是什么"，支撑 §九定级与阶段产物命名
  （命名=化学阶段产物：连接产物/二链cDNA/终文库，禁成分累加串）
- **真实账目不钳制**：过抽可为负（负值=吸及珠泥=携带），别清零
- **磁珠泥底双轨制**：0.55×珠悬液量的泥底只进液面估算（eff 取大），不进
