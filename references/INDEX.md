## 五、常见裁决（两个文档都能答时听谁的）

| 冲突 | 裁决 |
|---|---|
| 液体参数取值：05 区间 vs 11 分档 | **11 胜**（11 是实测数据，05 是经验兜底） |
| 模块配法：11 数据 vs 13 规律 | **13 定结构，11 定数值**（不冲突，组合用） |
| WD 工程能否程序化生成 | **09 胜**（可生成；03 的设置指南只是兜底形态） |
| wfp 与 py 不一致时信谁 | **wfp 胜**（08#14：WD 改参不导出时 wfp 是唯一权威源） |
| 负 Z | **官方允许、无限制**（课程 6；历史禁令 2026-09-02 解除）；推荐默认极低正 Z+降速，负 Z 刮底须水跑标定（13/11） |
| 排空 Z 怎么定 | **液面锚胜**（13 §七.4：有液面跟踪=打完后液面−0.4，带宽 −0.25~−1.0；体积档表/相对抬高只是无液面信息的回落档） |
| 方法名带公司前缀 | **禁止**（去标签化；04 命名规范） |
| 说明书风格参考 | **每次都问**（06 三问；旧说明书只是风格参考不是默认母版） |

## 六、维护约定（给未来更新本 skill 的自己）

1. 新经验进哪层：数据进 11、模块规律进 13、流程模式进 05、报错进 08、
   格式变化进 09、方法论进 00/10——**不新开文档，除非出现全新层**
2. 新增文档后同步三处：本文（分层地图+职责卡）、SKILL.md 索引、相关工作流段落
3. 引用一律写 `references/NN`，编号只增不改；废弃内容标"已弃用"而非删除
   （保留历史决策痕迹，如负 Z 禁令的解除记录）
4. 来源文件名/路径只进 `99`（本地档案、.gitignore 不入库），正文一律以编号回指；
   软件安装后的内部固定路径不算来源档案，可直接写正文
