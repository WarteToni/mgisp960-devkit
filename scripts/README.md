# scripts/ · 工具台账与调用约定

> 统一管理入口：什么工具、什么时候用、怎么调。详细场景路由见
> `references/INDEX.md` §三。

## 一、调用约定（两类工具）

| 类型 | 识别 | 用法 |
|---|---|---|
| **生成器** | 无"模板"字样 | 命令行传参，无硬编码路径，直接跑 |
| **模板** | 文件名带"模板" | 文件头部有 CONFIG 注释，**先改 CONFIG 再 `python3` 运行**；示例值均来自一步法参考项目，复用必须全部换成新项目值 |

**通用纪律**：
- 断言失败 = 交付禁止（模板内置计数/清零/去标签化断言，不许注释掉）
- 输出文件命名跟用户拍板的项目名走（去标签化，见 `references/06`）

## 二、工具清单

| 工具 | 类型 | 调用 | 服务于 |
|---|---|---|---|
| `spredo转wfp_生成器.py` | 生成器 | `python3 spredo转wfp_生成器.py <脚本.py> <模板.wfp> <输出.wfp> [工程名] [固定PCR方法名] [--sw 1.9.0.395]` | 功能 2b/3：py→wfp（AST 自动转换）；模板用 `最小骨架模板.wfp` 或用户任一单换台工程；限制见文件头（单换台结构、require2 不转换）；**操作指南见 `docs/生成WFP文件操作指南.md`** |
| `最小骨架wfp_合成器.py` | 生成器 | `python3 最小骨架wfp_合成器.py [输出.wfp] [--sw 1.9.0.395]` | 合成零依赖单换台最小骨架模板（产物 `最小骨架模板.wfp`，格式常量零公司/项目信息，内置记录流+布局双自检）；默认 395=现场实机版本，他版现场（如 398）用 `--sw` 重生成 |
| `wfp_builder.py` | 生成器 | `from wfp_builder import Wfp; Wfp(工程名, deck_main, deck_swap, sw="1.9.0.395")` | **WD 交付首选：直接生成**（不经 spredo/转换器）——API 直构活动树（block/parallel/loop/dely/pcr/液体，disp_name 语义命名，z 支持循环变量公式字符串）；样板 `scripts/wfp_builder_示例.py`；样板依据 09 §八 |
| `参考工程_结构示例.wfp` | 数据 | Reference-first 的结构金标准（09 §八） | 2026-09-10 现场实机验证可打开的完整工程：24 位台面全定义、Initialize+Block+Parallel 根结构、语义 DisplayName、395 串；只读基准，勿作生成器模板（模板用最小骨架） |
| `wfp后处理_模板.py` | 后处理 | `python3 wfp后处理_模板.py <in.wfp> <out.wfp>`（CONFIG①~⑤ 改项目真值） | 对生成器直出 wfp 做产线惯例对齐：阶段 Block 分组、全活动语义 DisplayName、Parallel 分支中文名、版本串归一（等长替换）；方法论 09 §八；**写出后必 hexdump 头 48B 验证** |
| `最小骨架模板.wfp` | 数据 | 作为生成器 `<模板.wfp>` 参数 | 仓库自带模板（合成来源见 `docs/生成WFP文件操作指南.md` §七） |
| `wfp活动schema.json` | 数据 | 随生成器自动加载，勿单独改 | 活动字段白名单（**防御性过滤**：395 实证含未知字段可打开，JObject 动态解析；保留 sanitize 是为只产出经验证字段）；生成器与审查维度 F 共用 |
| `生成英文版_模板.py` | 模板 | 改 CONFIG①（CN/EN 文件名）②（三块映射内容）后运行；内置 AST 等价验证 | 交付双语版（02 §五） |
| `生成自动化说明书_模板.py` | 模板 | 改 CONFIG①（母版/输出/项目名）②（替换表）③（品牌词清单）后运行 | 说明书克隆+替换+**去标签化断言**（06） |
| `自检_全面_模板.py` | 模板 | 改 CONFIG①（脚本）②（PCR XML，可选）③（装液量板位）④（废液板位+容量）⑤（换台识别词）⑥（枪头量程，默认带滤芯 165）后运行 | 交付前全面自检（07 第 2-3 层，11 类：含量程/排液≤吸液；负 Z 官方允许不报错）；审查维度 B/J/K 量化复用；**退出码 1 = 禁止交付** |
| `账本_全流程液量模拟_模板.py` | 模板 || `spredo直写账本审计_模板.py` | 模板 | 改 CONFIG①（脚本路径与名称）②（初始装载 build_state）③（换台/弹窗钩子）④（珠源井集合）⑤（关键终态断言）后运行 | **spredo 直写交付项目的账本**（13 §十直审形态）：mock spredo 直接 exec 脚本，零漂移、免 wfp 依赖；五类审计 + Z 锚审计（没入深度 ≥0.5mm）+ 8 头总量口径 |
 改 CONFIG①（wfp 清单）②（初始装载/换台/弹窗钩子）③（珠源井）后运行；**只读不写** | 全流程液量+液体身份+液面模拟（13 §十）：排空贴液面、吸液没入、混匀双约束、体系对账、装载五问审计；内嵌 wfp 解析器（尾字节断言） |

## 三、典型组合（按场景）

| 场景 | 工具组合 |
|---|---|
| 从零交付（工作流 A · spredo 直写） | **spredo直写账本审计_模板（S3 骨架→直审→回填）** → 英文版模板 → **全面自检** → 说明书模板 → zipfile |
| 从零交付（工作流 A） | **账本模板（S3 液面先行：骨架→账本→回填）** → 英文版模板 → **全面自检**（退出码 0 才继续）→ 说明书模板 → zipfile 打包 |
| py→wfp（工作流 B） | spredo转wfp_生成器（+ schema）→ WDesigner 实机验证 |
| 审查已有脚本（工作流 C） | **全面自检**跑量化部分（板流/语法/参数规则）；G 维按 13/11 人工核算 |
| wfp 直改 / 手改后对账 | 账本模板（改前：09 §七往返字节验证；改后：五项审计复跑） |

## 四、维护约定

1. 新增工具同步三处：本台账、`references/INDEX.md`、SKILL.md 索引
2. 模板类新工具必须遵守：头部 CONFIG 注释 + 示例值标注来源 + 内置断言
3. 工具内不出现公司名（去标签化同样适用于脚本注释与示例）
